## 🧭 PCA Plot — Principal Component Analysis

<img src="PCA_plot.png" alt="PCA Plot" width="650"/>

### Overview

The PCA plot projects the high-dimensional gene expression data onto a 2D plane to reveal the dominant sources of variation in the dataset. It is the **first quality check** for any RNA-Seq experiment.

### Details

| Parameter | Value |
|---|---|
| **X-Axis (PC1)** | Maximum variance direction — separates HBR vs UHR |
| **Y-Axis (PC2)** | Second-highest variance — minimal spread |
| **🔴 Red Points** | Healthy Baseline Reference (HBR), n=3 |
| **🔵 Blue Points** | Universal Human Reference / Disease (UHR), n=3 |

### Key Takeaway

> Complete separation with **zero overlap** between HBR and UHR along PC1 confirms a robust biological signal. The tight clustering within each group (especially HBR) demonstrates high reproducibility and low technical noise.

## 🌋 Volcano Plot — Differential Gene Expression

<img src="Volcano_plot.png" alt="Volcano Plot" width="650"/>

### Overview

The Volcano plot displays every gene's **fold change** against its **statistical significance**. Red dots represent Differentially Expressed Genes (DEGs) that pass both thresholds.

### Details

| Parameter | Value |
|---|---|
| **X-Axis** | Log2 Fold Change (UHR vs HBR) |
| **Y-Axis** | -Log10(Adjusted P-value) |
| **🔴 Red Dots** | Significant DEGs (`padj < 0.05`, `\|Log2FC\| > 1.0`) |
| **⚪ Gray Dots** | Non-significant genes |
| **Dashed Lines** | Threshold boundaries (FC = ±1, padj = 0.05) |

### Key Takeaway

> **Bilateral transcriptional response** — approximately 60-80 upregulated genes (right, Log2FC up to +1.9) and 70-90 downregulated genes (left, Log2FC down to -3.0). The tight gray cluster around (0,0) confirms low technical noise and reliable normalization.

## 🔥 Heatmap — Top 20 Differentially Expressed Genes

<img src="Heatmap.png" alt="Heatmap" width="650"/>

### Overview

The Heatmap shows Z-score normalized expression levels of the **top 20 DEGs** across all 6 samples, revealing per-gene expression patterns and sample-level reproducibility.

### Details

| Parameter | Value |
|---|---|
| **Rows** | Top 20 DEGs (ERCC spike-in genes, e.g., ERCC_035, ERCC_062) |
| **Columns** | 6 samples — HBR (3 replicates) + UHR (3 replicates) |
| **🔴 Red** | High expression (upregulated in UHR, Z-score ≈ +1.5 to +2.0) |
| **🔵 Blue** | Low expression (downregulated in HBR, Z-score ≈ -1.0) |
| **⚪ White** | Baseline expression (Z-score ≈ 0) |

### Key Takeaway

> All 20 top DEGs show a **uniformly consistent pattern**: low in HBR (blue), high in UHR (red). Replicates within each group are nearly identical, confirming high experimental reproducibility. Subtle intensity variations reveal sub-clusters of "highly induced" vs "moderately induced" biomarker candidates.
